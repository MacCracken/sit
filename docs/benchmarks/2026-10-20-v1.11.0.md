# Benchmarks — 2026-10-20 (v1.11.0)

cyrius **6.7.15** for both builds (DCE). The previous snapshot is [`2026-10-20-v1.10.0.md`](2026-10-20-v1.10.0.md).

⚠ **The host was saturated** (load average 20–27 on 16 cores) for every run here. Only per-process CPU time is reported, and even that moves by ±10% between identical runs at this load.

## Server CPU per request — the one cost 1.11.0 adds

Every `sit serve` request is now a store session (a shared `flock`, an unlock, and a `stat` of `objects.patra` once the store is open; [ADR 0017](../adr/0017-serving-many-repositories.md)). Measured from `/proc/<pid>/stat`: 4,000 requests per run, 6 alternating runs, minimum, against the packed 1,600-commit fixture:

| | 1.10.1 | 1.11.0 | 1.11.0, sessions disabled |
|---|---:|---:|---:|
| `GET /sit/v1/refs` | 125–127 µs | 130–132 µs | 127.5 µs |
| `GET /sit/v1/objects/<HEAD>` | 430–475 µs | 467–485 µs | 470 µs |

`/refs` pays about +5 µs (the lock and unlock; it never opens the store). Object reads are within the run-to-run noise. The same build with sessions compiled out measured the same as with them (470 against 467.5 µs), and a build keying the mapping cache by the relative path as before measured 480 against 485.

## Commands — unchanged paths

CPU time, minimum of 7 alternating runs, 1.10.1 → 1.11.0. A command's only new work is one `stat` when it opens the store, about 1 µs. The spread below (−23% to +1%) is the host's load, not either build: `status` has no change on its path.

| operation | 1.10.1 wall | 1.11.0 wall | 1.10.1 cpu | 1.11.0 cpu |
|---|---:|---:|---:|---:|
| add x100 (one file each) | 176.7 | 159.8 (-9.5%) | 158.3 | 140.3 (-11.4%) |
| commit | 2.6 | 2.6 (+0.8%) | 2.4 | 2.4 (-1.2%) |
| status, 200 files | 9.9 | 7.6 (-23.2%) | 9.7 | 7.4 (-23.4%) |
| log --oneline, 300 commits | 46.3 | 46.5 (+0.5%) | 45.9 | 46.2 (+0.9%) |
| checkout 100 changed files, there and back | 104.7 | 94.7 (-9.5%) | 103.6 | 93.9 (-9.3%) |
| clone, 100 commits | 72.3 | 72.6 (+0.4%) | 72.1 | 72.4 (+0.4%) |
| fsck, 100 commits | 69.4 | 63.8 (-8.0%) | 69.1 | 62.8 (-9.1%) |
