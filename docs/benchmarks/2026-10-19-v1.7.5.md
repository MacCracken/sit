# Benchmarks — 2026-10-19 (v1.7.5)

cyrius **6.7.15** for both builds (DCE). The previous snapshot is [`2026-10-19-v1.7.4.md`](2026-10-19-v1.7.4.md).

⚠ **The host was saturated when this was taken.** Other builds held the load average at 18–40 on 16 cores throughout. The standard `tests/sit.bcyr` and `scripts/benchmark.sh` runs were taken, interleaved, and are **not published**: unchanged code moved by up to ±46% between runs (`sha256-64B` read 3.29 µs, against 709 ns on a quiet host). Wall-clock A/B runs on the changed paths showed 1.7.5 5–10% slower, all in one direction. Re-measured by each child's own CPU time, which excludes the time it spent preempted, the difference is gone (below). Re-take the standard tables on a quiet host.

## Memory — the release's subject (exact counts, unaffected by load)

Global bump-heap bytes kept per operation, measured in-process.

`sit serve` ref push, 2,000-commit history (through `serve_handle_request`):

| ref push | 1.7.4 | 1.7.5 |
|---|---:|---:|
| refused (walks 1,999 commits) | 9,072,032 | 63,968 |
| accepted fast-forward (walks 1,999 commits, writes the ref) | 9,073,864 | 63,968 |
| no-op | 152 | 0 |

git read mode, per object read through `read_object`, beyond the inflated object the caller keeps:

| repo | 1.7.4 | 1.7.5 |
|---|---:|---:|
| packed, 320 blobs at depth 50 | 672 (1,048 with a repo root set) | 0 |
| loose, small files | 56 (208 with a repo root set) | 0 |
| loose, 190 KB text files | ~68,700 | 0 |

What 1.7.5 still keeps is sankoch's `br_init`, 32 B per inflate: the 63,968 B above is 1,999 × 32. Per read that is 32 B for a loose object and about 1 KB for a packed one at this repo's average chain depth of 33. It is an upstream ask.

## Time — the changed paths, A/B by CPU time

Each child's user + system CPU time, minimum of 20 runs, with 1.7.4 and 1.7.5 alternating:

| operation | 1.7.4 | 1.7.5 | Δ |
|---|---:|---:|---:|
| `log --oneline`, 2,000 commits (`parse_commit_body` per commit) | 315.8 ms | 318.2 ms | +0.8% |
| `checkout` of 500 files and back (`sf_write_all` / `ensure_parent_dirs` per file) | 559.6 ms | 557.0 ms | -0.5% |
| in-process: read 320 packed blobs at depth 50 | 1025.3 ms | 1032.9 ms | +0.7% |
| `sit serve`: 24 ref pushes over 2,000 commits | 4052.7 ms | 3979.7 ms | -1.8% |

Flat. Absolute times are about 3× a quiet host's, because cores were shared; the comparison is between builds under the same conditions.

The new 4–8 KiB stack buffers in the path helpers cost nothing per call: a call with 8.4 KB of stack arrays measured 7–8 ns, the same as one without, because cyrius does not zero them.
