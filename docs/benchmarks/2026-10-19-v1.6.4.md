# Benchmarks — 2026-10-19 (v1.6.4, closes 1.6.x)

cyrius **6.6.20** (sigil 3.13.10 / sankoch 2.8.1 / patra 1.15.2). The 1.6.x closeout baseline: 1.6.3 and 1.6.4 measured back to back on the same host, so the comparison isolates what the 2026-10-19 audit fixes cost. The previous snapshot is [`2026-08-19-v1.4.8.md`](2026-08-19-v1.4.8.md); the cyrius 6.5.29 → 6.6.20 move in between is covered in the 1.6.3 CHANGELOG entry (the only material change there is `ed25519-sign` ~2×, sigil's constant-time public-key re-derivation).
