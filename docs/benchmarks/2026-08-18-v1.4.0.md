# Benchmarks — 2026-08-18 (v1.4.0)

Measured on cyrius **6.5.26**. The prior snapshot (v1.3.7) was taken on **6.5.24**,
so the two are NOT directly comparable — see the note below before reading deltas.

## The is_ignored shift is the toolchain, not sit

`is_ignored-*` reads ~10% slower than the v1.3.7 snapshot. That is **not** a sit
regression, and specifically **not** the `_wildmatch` step budget added in v1.3.8.
Isolated by building v1.3.7's `src/index.cyr` — which has no budget at all — against
the current toolchain and benching it:

```
is_ignored-50pat
  v1.3.7 source, no budget,    cyrius 6.5.26 : 36.552us
  v1.4.0 source, budget @entry, cyrius 6.5.26 : 36.415us
  v1.4.0 source, budget @star,  cyrius 6.5.26 : 35.608us   <- shipped
  v1.3.7 snapshot,              cyrius 6.5.24 : 32.365us
```

The un-instrumented source is the SLOWEST of the three same-toolchain builds, so the
budget costs nothing measurable; the gap to the old snapshot is 6.5.24 → 6.5.26
codegen. v1.4.0 does move the counter from function entry into the `*` branches only
(the other paths are already bounded by min(plen, slen)), which is the right shape
regardless — it just doesn't show up at this resolution.
