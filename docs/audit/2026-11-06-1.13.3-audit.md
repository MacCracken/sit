# 2026-11-06 — security pass for 1.13.3

**Scope**: two findings of one class, from thoth 0.55.3's hostile pass on a real AGNOS guest (agnos 1.57.17) and its suite on a real Mac. Severity as [CLAUDE.md](../../CLAUDE.md) defines it.

## Finding closed

| id | severity | finding | fix |
|---|---|---|---|
| thoth 0.55.3 | MEDIUM | `path_is_symlink`, `path_lstat_kind` and `path_lstat_mode` used the following `stat#33` on AGNOS, so every symlink guard was a no-op there. `.git -> ../v/.git` read another repository, 1.13.1's refusal among the guards that did nothing | `_agnos_lstat_mode`: `lstat#102`, with `stat#33` only where a volume cannot hold a link |
| thoth 0.55.3 | MEDIUM | `VAL_AT_FDCWD` and `VAL_AT_SYMLINK_NOFOLLOW` were Linux's on every target. Darwin's `fstatat64` wants -2 and 0x20, so every lstat on macOS failed with EBADF and every symlink guard read "not a link" | per-target values, in `src/util.cyr` |

The comment that kept this in place called it an accepted degradation, because the frozen ABI had no lstat. That was true when written and stale from agnos 1.56.53. A degradation that names a missing floor call has an expiry date.

## Reviewed

- **Buffer:** `abuf[128]` against the kernel's 48-byte stat struct, §4.1 of agnos's userland ABI. `STAT_MODE` is 0 on that target.
- **The fallback:** `stat#33` runs only when `lstat#102` fails. On ext2 a missing path fails both, so it still reads as absent, and a dangling link succeeds at lstat, so it still reads as a link.
- **What the guards newly do on AGNOS:** the `sf_*` wrappers now refuse planted links there, and `path_lstat_kind` reads a link as `0xA000` rather than its target's kind. That is what they do on every other target, and an honest repository on a guest reads as before.

## Left open

- **Windows.** `syscall(262, ...)` has no reroute there, so the guards are off on that target too. Its lane does not build past its POSIX-only paths, so nothing reaches them yet.
- **`_lstat_uid` still answers -1 on AGNOS.** `getuid` is a stub there, so an owner check has nothing to compare with until the kernel has one.
- **Links below a real store** stay on the roadmap's 1.13.4, on every target.
- **No target but Linux runs sit's own suites in CI.** Both findings came from a consumer's lanes. A macOS leg would have caught this one.
